# Data provenance and redistribution boundary

## Reference corpus

The reference analysis represented by this companion application was produced from the **Landini–Stolfi Interlinear (LSI) IVTFF archive**, using the **Takeshi Takahashi `;H` EVA transcription stream** together with the archive metadata used by the project to distinguish Currier-language / section groupings.

The source archive identifies Takeshi Takahashi's contribution as a complete single-handed Voynich transcription and uses `H` as its transcriber code.

## What this repository redistributes

This repository intentionally does **not** redistribute the original IVTFF source transcription.

The self-contained Guided Demo includes only project-derived data products from the reference run, including:

- aggregate counts and frequency distributions;
- information-theoretic result summaries;
- trained conditional count / transition tables used by the demonstration compilers;
- reference compression and geometry measurements;
- synthetic text generated by the project's own compiler.

These derived demonstration materials are stored primarily in:

`data/demo_data.json`

They are intended to let the GUI reproduce the project's guided demonstrations without embedding the underlying source transcription.

## Full Reproduction mode

The application includes an optional **Full Reproduction** mode.

A researcher may independently obtain a compatible IVTFF source file and select it in the application. The program then parses the selected source and recomputes the implemented tests directly instead of relying on the bundled reference summaries.

This separation provides two paths:

1. **Guided Demo:** a self-contained accessibility layer using derived aggregate material.
2. **Full Reproduction:** an audit path using an independently obtained compatible source transcription.

## Redistribution boundary

The project references the source transcription and its contributors rather than asserting ownership of the transcription itself.

No explicit redistribution license for the complete source transcription is asserted by this repository. The original transcription is therefore kept outside the distributed application and repository.

The project-authored derived demo material is separately licensed as described in `LICENSE-CONTENT.md`.

## Executable release

The compiled Windows release bundles the same guided-demo aggregate data and project assets used by the Python application. It does **not** bundle the IVTFF source transcription.

The executable is a convenience distribution of the source code in this repository; the Python source and Windows build script remain available for inspection and independent rebuilding.
